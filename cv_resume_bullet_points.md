# Software Engineering Project - CV Bullet Points

**Project Title:** Enterprise HR & Management Dashboard  
**Role:** Full Stack Developer  
**Technologies Used:** React.js, Vite, Tailwind CSS, Firebase (Auth, Firestore, Hosting), JavaScript (ES6+), Git

### Core Achievements for Your Resume:

* **Role-Based Access Control (RBAC) Architecture:** Architected a secure authentication pipeline using Firebase Auth and React Context API to dynamically enforce view-level and component-level permissions across 3 hierarchical tiers (Admin, Manager, Employee), preventing unauthorized data mutation.
* **Automated Bulk Payroll Engine:** Engineered a high-performance O(N) bulk execution algorithm that simultaneously processes company-wide financial contracts. The system dynamically computes individualized overtime bonuses and 3-strike attendance penalty offsets before pushing sanitized payload arrays to the NoSQL cloud database.
* **Intelligent Data Ingestion System:** Developed a robust CSV data parsing engine that sanitizes bulk spreadsheet uploads, prevents redundant database collisions, and normalizes unstructured text into strictly typed financial schema objects (e.g., parsing Base Salary and Penalty Rates).
* **Real-time State Synchronization:** Diagnosed and resolved complex React-Firebase phantom state bugs by perfectly aligning asynchronous NoSQL Document IDs with local ephemeral memory, ensuring 0ms latency UI updates during attendance tracking interactions.
* **Enterprise UI/UX Design:** Designed a modern, responsive, dark-mode compatible interface utilizing Tailwind CSS, featuring conditional layout rendering and protected route middleware to ensure a seamless cross-device user experience.
* **CI/CD & Cloud Deployment:** Configured Single Page Application (SPA) routing protocols and deployed the optimized production build to Google's Firebase Hosting global content delivery network (CDN) with integrated SSL security.
